# AI Usage Disclosure

As required by academic integrity guidelines, AI tools were used in this project for coding support, debugging, report organization, and documentation assistance.

### Claude (Anthropic)

Claude was primarily used to assist with Python coding and analysis workflow development.

Examples of prompts used include:

- "Help clean and merge Steam, SteamSpy, and VGSales datasets and create a popularity-related feature."

- "Generate exploratory data analysis code for price distributions, free vs paid comparisons, genre analysis, and correlation heatmaps."

- "Help implement hypothesis tests for popularity comparisons, price categories, playtime correlation, genre effects, and user score analysis."

- "Generate machine learning workflows using Linear Regression, Random Forest, and K-Means clustering for predicting video game popularity."

Claude outputs were used as coding assistance and were reviewed, modified, tested, and integrated into the final notebooks by the student.

### ChatGPT (OpenAI)

ChatGPT was mainly used for:

- Organizing the structure of the final report
- Improving README and markdown formatting


All analysis decisions, interpretations, statistical conclusions, and final project outputs were reviewed and completed by the student.
